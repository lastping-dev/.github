# Getting help

- **Documentation:** start at [lastping.dev](https://lastping.dev). The API reference is at [app.lastping.dev/docs](https://app.lastping.dev/docs), the MCP setup guide at [lastping.dev/mcp](https://lastping.dev/mcp/), and the Terraform guide at [lastping.dev/terraform](https://lastping.dev/terraform) with the full schema on the [Terraform Registry](https://registry.terraform.io/providers/lastping-dev/lastping).
- **Is it down?** Check the public status page: [app.lastping.dev/status/lastping-self](https://app.lastping.dev/status/lastping-self).
- **What changed?** See the [changelog](https://lastping.dev/changelog).
- **Email:** [hello@lastping.dev](mailto:hello@lastping.dev) for questions, account help and anything about the hosted service.
- **Bugs and feature requests** for the provider or the CLI: open an issue in that repository. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security issues:** see [SECURITY.md](SECURITY.md). Never in a public issue.
